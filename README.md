# PerceptTwin

Project website for **PerceptTwin: Semantic Scene Reconstruction for Iterative LLM Planning and Verification**, accepted to ICRA 2026.

The site is hosted with GitHub Pages from the repository root. To preview it locally, run:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Structure

- `index.html` — main project page
- `output.html` — embedded rollout gallery
- `static/` — styles, scripts, paper, code archive, images, and videos

The page is based on the [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template).
